# 05 消融实验设计

> 基于最终架构（微调4B + classify-then-explain + 单帧 + 大小模型验证）
> 日期：2026-08-15

---

## 1. 实验目标

1. Q1：微调 4B 是否优于零样本 VLM？
2. Q2：小模型复检层的边际贡献多大？
3. Q3：温度校准和每类别阈值的价值？
4. Q4：分层推理（Tier1 vs Tier2）的精度-延迟权衡？

---

## 2. 评测指标

| 指标 | 说明 |
|---|---|
| mAP (mean Average Precision) | 多标签分类主指标 |
| Per-class AP | 每个原子行为的 AP |
| Macro-F1 | 各类 F1 平均 |
| Primary accuracy | 主导类别分类准确率 |
| ECE | 置信度校准误差 |
| Subset accuracy | 全标签匹配率 |
| Hamming loss | 单标签错标率 |
| P95 延迟 | 95% 请求延迟 |

## 4. 统计显著性

对每对实验用 McNemar's test (p<0.05) + Bootstrap 95% CI (1000次重采样)。
